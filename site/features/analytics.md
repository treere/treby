# Analytics Dashboard

Track your hiring metrics with a clean analytics dashboard.

![Analytics Dashboard](/screenshots/10-analytics.png)

## Metrics

- **Total Candidates** — count of all candidates in the tenant
- **Avg. Time to Hire** — average days from first application to hired
- **Active Jobs** — number of open job postings
- **Pipeline Overview** — horizontal bar chart showing candidate counts per stage across all jobs
- **Stage Conversion Rates** — percentage of candidates progressing from one stage to the next

## What you can learn

- Where are candidates getting stuck? (bottleneck stages)
- Which stages have the highest drop-off?
- How long does it take to fill each role?
- Are we interviewing enough people?
