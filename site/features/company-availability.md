# Company Availability

Define your company's default working hours and timezone. Every new team member automatically starts with a copy of this schedule — no per-person setup required on day one.

## How it works

1. An **admin** opens **Settings → Company Availability**
2. They set the **Company Timezone** and the default weekly time blocks (e.g. Monday–Friday, 09:00–13:00 and 14:00–18:00)
3. When a new user is created, Treby copies those blocks into the user's own availability and sets their timezone to the company default
4. Each user can still edit or add their own blocks later in **Settings → Availability** — changing one person never affects the company template or anyone else

## Company Timezone

The company timezone is the default for new users and is used to interpret the company's default time blocks. Change it any time in **Settings → Company Availability**; existing users keep the timezone they were created with unless they change it themselves.

## Default time blocks

Admins can add, edit, and delete the company's default blocks. Multiple non-overlapping blocks per day are supported (for example a morning and an afternoon window). These blocks become the starting point for every new hire's schedule.

## Who can configure it

Only users with the **admin** role can open **Company Availability**. Non-admins who try to open the page are redirected away.

## Availability fallback

When a user has not customized their own hours, scheduling falls back to the company template so interviews can still be booked. If no company template exists, no slots are produced for that user.
