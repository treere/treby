# Lingua / Language

Treby is fully bilingual — Italian and English — across the entire interface.

## Switching language

1. Open **Settings → Language**.
2. Select **Italiano** or **English**.
3. Save — the choice is stored on your account and applied on every page (dashboard, jobs, candidates, pipeline, interviews, settings, candidate portal, career pages).

You can change language at any time; the interface updates immediately.

## What is translated

- Navigation and layouts (Jobs, Candidates, Interviews, Analytics, Settings, etc.)
- Dashboard headings, weekly stats, My Actions, empty states, activity feed, pipeline overview
- Forms, buttons, flash messages and error messages
- Candidate portal and public career pages

If you see an English sentence while using Italian, please report it — the automated translation guard prevents new untranslated strings from being merged.

## For contributors

New user-facing text must be wrapped with `gettext`:

```elixir
gettext("My Actions")
gettext("Welcome, %{name}!", name: @user.name)
```

Then extract and translate:

```bash
mix gettext.extract --merge
# fill priv/gettext/it/LC_MESSAGES/default.po
mix treby.check_translations        # fails if any Italian msgstr is empty
mix credo --strict                  # flags hardcoded strings outside gettext
```

Both checks run in `mix precommit` and in CI.
